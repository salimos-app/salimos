Sunset UI Palette

Datos reales del colormap plasma (matplotlib, dominio público), recortados y recorridos al revés para quedarse en la franja "sunset → dusk → night" del isotipo de Salimos — pensada para botones, pines y badges de la UI. El mapa no usa esta paleta (de momento). Fuente: src/theme/plasmaData.ts + sunsetPalette.ts + sunsetUi.ts.
